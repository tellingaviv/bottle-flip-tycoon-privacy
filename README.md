# Informativa sulla privacy — Bottle Flip Tycoon: Idle Empire

Questo repository contiene **solo** l'informativa sulla privacy del gioco, pubblicata come pagina
web tramite GitHub Pages.

**Indirizzo pubblico:** https://tellingaviv.github.io/bottle-flip-tycoon-privacy/

È quello da incollare in App Store Connect e nel Play Console.

## Perché è un repository separato

Il codice del gioco sta in un repository **privato**, e GitHub Pages sui repository privati
richiede un piano a pagamento. Tenere qui la sola informativa — che è un documento destinato a
essere pubblico — costa zero e lascia privato il resto.

## Come si aggiorna

Si modifica `index.html` e si fa un push: GitHub Pages ripubblica da solo in un paio di minuti.

Va aggiornata **prima**, non dopo, ogni volta che cambia cosa il gioco raccoglie. I due casi
già previsti nel testo:

- accendere gli identificativi AdMob veri (il testo li descrive già, non cambia niente);
- accendere le funzionalità online — classifiche, account, salvataggi cloud. Il testo dice
  esplicitamente che oggi non sono attive: quando lo diventano, quella sezione va riscritta e
  la data in cima aggiornata.

## Cosa contiene

Una pagina sola, in inglese e italiano, con selettore di lingua. Si apre da sola nella lingua del
browser e accetta `#it` o `#en` nell'indirizzo per forzarne una.
